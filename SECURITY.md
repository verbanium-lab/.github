# Security policy

This policy applies to every repository of `verbanium-lab` that has no `SECURITY.md` of its own.

## Report a vulnerability

Report privately through GitHub: open the
[Security tab of verbanium-lab/.github](https://github.com/verbanium-lab/.github/security) and choose
**Report a vulnerability**. Do not open a public issue, pull request or discussion about it.

Include what is affected (site, repository or package), how to reproduce it and the impact you
expect. You will get an answer in the private report.

## Supported versions

Only the latest release of each app and package, and what currently runs in production, receive
security fixes.
